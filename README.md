# Facilities Management Specialist: The Complete Course on Facilities Management – course website

Course microsite for ICL, live at https://facilitiesmanagementtraining.co.za.

* Static HTML, deployed by Netlify from this repository (publish directory: root).
* Forms use Netlify Forms: `facilities-registration`, `-enquiry`, `-inhouse-proposal`, `-brochure-request`.
  Set a form-notification email to training@za-icl.com in Netlify (Site configuration → Notifications).
* Each submission includes `lead_source`, UTM fields, `gclid` and `li_fat_id`, so you can see which campaign produced it.
* Thank-you pages fire conversion events (Google tag / LinkedIn Insight) once IDs are set in `courses.py` of the builder.

The pages are generated by the ICL course-site builder (`build.py` + `courses.py`). Change content there and rebuild,
rather than editing the HTML by hand.
